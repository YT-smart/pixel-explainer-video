# 从文案到分镜

## 1. 解说文案结构（帮用户写文案时用）

以人物/IP 拆解为例（书籍、品牌、概念同理替换）：

1. **数字钩子（1–2 句）**：最反差、最具体的成绩。“他靠短视频，把公司年营收做到过亿，又拿出 500 万……”
2. **核心看点（1–2 句）**：这期真正要讲的东西。“但他最厉害的地方，是……”
3. **栏目名 + 主角**：“百大IP拆解，今天聊 XX。”
4. **经历线（按时间）**：每一段 = 做了什么 + 结果数字。
5. **拆解观点（加粗，穿插 3–5 次）**：主讲人跳出故事做分析，“从这段经历看……”“这里的小切口是……”。
6. **方法论/体系**：把经验整理成几个可复用的部分（几大结构、几大元素），举 1–2 个具体例子。
7. **收束**：体系的价值 + 一句可传播的金句。

语言要口语、短句、少形容词；数字要具体；每段第一句就点明这段讲什么。1 分钟约 260 字。

## 2. 切分章节和场景

- **章节**（3–6 个）：按文案的大段落，用于顶部章节条，名字 2–6 个字（“起点”“挑战100天”“一块钱表格”）。
- **场景**（每 8–25 秒一个）：一个场景 = 一个背景 + 一组围绕同一件事的 UI。经历段落一般一段一个场景；每个加粗观点段单独一个黑板房场景。
- 场景边界放在句子边界（`segments.txt` 里的停顿处）。
- 对标视频大约 4–5 分钟 20 个场景左右。

## 3. 每段找一个游戏化比喻

先问自己：这段话在讲“获得了什么 / 达成了什么 / 经历了什么 / 卡在哪里 / 怎么解决”？对照下表选画面（`px` 里都有现成的背景和组件）：

| 这段在讲 | 推荐画面 | pixkit |
|---|---|---|
| 开头成绩、规模 | 夜景城市 + 成就解锁 + 计数器 + 大楼升起 | `bg_city_night` `counter` `card(... img=ICONS["trophy"])` |
| 核心观点/“当成一门学科” | 书房 + 一本发光的书 + 零散纸片飞入书中 + 装备卡 | `bg_study` `desk` `ICONS["book"]` |
| 介绍人物 | 舞台聚光 + 金相框像素头像 + 主讲人小人 + 栏目名 | `bg_stage` `framed` `photo_portrait` `badge` |
| 早年经历 | 横版闯关，地标=学校/球场/公司，职业变化=LEVEL UP | `SideScroll` `player_hud` `level_up_beam` |
| 做了一个系列/坚持 N 天 | 日历墙逐格点亮 + DAY 计数 | `bg_calendar` `fill_calendar` |
| 帮别人/服务客户 | 商业街 + NPC 走来 + 对话气泡 + 放大镜扫过店铺 | `bg_street` `random_npcs` `bubble` `ring` |
| 卖东西卖不动 | 直播间 + 在线人数 + 弹幕 + “成交 0” | `bg_live_room` |
| 用户和购买之间的门槛 | 悬崖鸿沟 + “距离” | `bg_chasm` |
| 低门槛产品/小切口 | 道具掉落 → 打包成礼盒 ¥1 → 变成桥 → 用户走过去 | `draw_bridge` `bridge_y` `ICONS["gift"]` |
| 业绩数字 | 展厅金色柱状图 + 房子/钥匙等奖励图标 | `bg_hall` `gold_bar` `ICONS["house"]` |
| 几个环节的分工 | 接力：几张卡用箭头串起，小头像沿着走 | `card` `arrow` |
| 误区/只看一面 | 两行“只看 A → 漏掉 B”，红色 ✗ | `ICONS["cross"]` |
| 整理出体系 | 展厅展品台 + 卷轴道具 | `pedestal` `ICONS["scroll"]` |
| N 大结构/元素 | 卡片矩阵，说到哪个点亮哪个 | `card` 循环 |
| 举例子（修车、门头…） | 对应行业的小场景 + 进度条 | `bg_garage` `draw_car` `progress_bar` |
| 诊断/检查 | 体检单：逐项打 ✓/✗ | `ICONS["check"/"cross"]` |
| 可复制、规模化 | 一个小人 → 一排小人 | `draw_char` 循环 |
| 结尾总结 | 黑板：不同项目方块 → 共同问题落成地基 | `bg_chalk_room` |

没有合适的就组合：背景选情绪，UI 讲信息。

## 4. 动画时间点

- 每个视觉元素绑定一个“触发词”：`T_X = tl.cue("触发词", 大约秒数)`，元素在 `T_X` 出现。
- 同一句里多个并列词（“营销、账号、选题、脚本”）各自绑定，依次弹出，节奏自然跟着配音。
- 元素在下一个话题开始前 0.2 秒淡出（`out=` 参数）。
- 场景开头 0.3 秒内放第一个元素，避免空镜。

## 5. 主讲人点评场景（加粗段落）

固定格式让观众一眼知道“这是分析”：黑板房背景、主讲人 scale=3 站右侧（x≈440）、左上角「XX拆解」徽章、黑板上用粉笔色文字 + 卡片 + 箭头画逻辑图。黑板可用区域约 x 120–1560、y 90–770（高分辨率坐标）。

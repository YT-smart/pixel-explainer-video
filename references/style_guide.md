# 风格指南：像素游戏风解说

对标样本：B 站「一只索尔」系列（如《滚雪球》解读）。下面是拆解出来的、本技能要复刻的要素。

## 1. 画面

- **分辨率感**：场景在 480x270 上画，放大 4 倍。每个“像素”= 屏幕 4px，硬边、无抗锯齿。放大必须用最近邻（NEAREST）。
- **色调**：暗底 + 暖光。主色是深藏青/深棕（夜晚、书房、展厅），强调色是琥珀金 `(255,190,60)` 和橙 `(255,150,40)`，警示用红 `(235,70,60)`，正向用绿 `(110,210,120)`。白天场景（街道、黄昏）用来做情绪转换，不要通篇亮色。
- **光影**：一切光都“分级”：天空用 6–8 段色带，光晕用 4 级同心椭圆，台灯/聚光灯用半透明光锥。四角统一压暗（vignette）。这是“高级感”的主要来源。
- **常驻场景类型**：夜景城市、书房（台灯+书架+窗外月亮）、舞台聚光、展厅（展品台+聚光）、黑板房、日历墙、商业街、直播间、悬崖鸿沟、黄昏横版关卡、车库。

## 2. 角色

- 20x30 像素的大头小人（头占一半），放大 2 倍（远景）或 3 倍（主讲人近景）。
- 只靠 4 个特征让人认出是谁：**发型、眼镜、上衣颜色/款式、下装**。照片里最显眼的特征一定要做出来（比如刺猬头、圆框眼镜、黄短裤）。
- 动作很克制：待机呼吸（每 0.6 秒上下 1 像素）、偶尔眨眼、走路两帧交替。不做复杂动作——靠 UI 和道具讲故事。
- 真人照片做成**像素头像**放进金色相框（“传记封面”感），或做成左上角玩家状态条里的小头像。

## 3. 游戏化 UI（核心）

所有概念都翻译成游戏语言，这是这个风格最有记忆点的地方：

| 内容 | 游戏化表达 |
|---|---|
| 一个重要概念/方法/工具 | 道具卡：「获得道具：XX ★★★★★ 传说级装备」 |
| 一个里程碑/数字成就 | 顶部弹出「成就解锁：XX」+ 奖杯图标 |
| 人物成长阶段 | 左上角玩家状态条：头像 + 名字 + Lv.N + 职业；「LEVEL UP!」弹窗 |
| 人生经历/时间线 | 横版闯关：主角往右走，地标（学校、公司）依次经过 |
| 数字增长 | 计数器滚动、金币飞、金色柱状图升起 |
| 两难选择/门槛 | 悬崖鸿沟、天平、「是否XX？是/否」对话框 |
| 失败/误区 | 红色 ✗、「最差」印章、错误音效 |
| 体系/框架 | 卡片矩阵（四宫格/八宫格）逐个点亮 |
| 章节 | 顶部章节导航条，当前章节金色下划线 |
| 主讲人观点 | 黑板房 + 主讲人站右侧 + 左上角「XX拆解」徽章 |

UI 面板统一样式：4px 粗金边 + 切角 + 深色底（`px.panel`）。弹出用回弹缓动（back_out），约 0.35 秒。

## 4. 字幕

- 底部居中，白色粗体 + 黑描边，**每句 1–2 个关键词橙色**。
- 一屏一句，字幕跟着配音逐句切换，不做逐字跳动。
- 画面里的大字（卡片、标题）和字幕可以重复关键信息，这是这种风格的常态——观众静音也能看懂。

## 5. 节奏与转场

- 每 3–6 秒画面要有一次“事件”（弹卡、道具出现、镜头变化）。说到某个词时，对应的视觉元素在那一刻出现——这是看着“精致”的关键。
- 场景切换用 0.1 秒闪黑；同一场景内部用元素进出（淡入、回弹、飞走）。
- 数字、成就、升级这些“爽点”配音效，信息密集段落减少音效。

## 6. 声音

- 配音为主（音量最大），音效其次，BGM 最轻（几乎听不出旋律，只有律动）。
- 音效全是 8-bit 方波/三角波合成：弹出“哔”、成就上行琶音、升级六音琶音、金币两音、印章低频“咚”、错误低频“嗡”。
- BGM：三角波低音 + 轻琶音，每章换一组和弦，避免几分钟同一循环。
